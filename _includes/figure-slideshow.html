Usage: {% include figure-slideshow.html %} Used twice — beside the About paragraphs on the homepage and beside the intro prose on /research/ — so both pages page through one implementation rather than two copies of the same markup. .figure-split is the two-column layout it sits in; both callers use it. A slide is the figure, its caption, its research-area tags, and the link to the paper it came from, in that order. Areas are optional. The IsoCompute entry carries `areas: []` on purpose — it is a study of LLM reasoning and belongs to none of the lab's named areas — so the chip row is guarded and that slide renders no row at all rather than an empty one holding its margin. Chips prefer each area's `card_title` ("Offline RL") over its full `title` ("Offline reinforcement learning"): three full titles wrap to three rows in this column and read as a paragraph rather than as tags. Those values carry HTML entities, so they are not escaped. `alt` is a different thing from the caption: it is never shown, only read aloud, and the two say different things — the caption says what the figure means, the alt says what it depicts. It is escaped because some entries quote a label off the figure — the SPIN alt text contains a double quote that would otherwise end the attribute early. Machinery is the shared carousel: assets/js/carousel.js finds this by data-carousel and adds the paging controls. It is the .carousel-solo variant, the same one-per-page shape as the hero slideshow. The viewport is a snapping scroll container that already holds every figure, so with JS off, by keyboard, or under a screen reader every figure stays reachable and nothing is hidden. The figures are shuffled on every page load, using the same parser-blocking Fisher-Yates approach as the current-student tiles. The shuffle runs before deferred carousel.js measures the track, so paging, tab order, and screen reader order all describe the randomized arrangement. data-carousel-autoplay is the opt-in for advancing on its own, in milliseconds. It is per instance and not implied by .carousel-solo, so the research-area and student carousels — which are navigation — stay manual, and the hero can opt in by adding this one attribute once it has photographs. The script pauses it on hover and focus, in a hidden tab, and for good as soon as the reader pages by hand, and does not run it at all under prefers-reduced-motion. Slide changes are not announced: a live region firing every twelve seconds would talk over whatever the reader is on.
