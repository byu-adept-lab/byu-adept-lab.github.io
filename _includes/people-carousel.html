{%- comment -%} One people group as a rotating carousel of horizontal tiles, three to a page, stacked as rows. Usage: {% include people-carousel.html group="current" label="current students" %} Same machinery as the research carousel on the homepage: assets/js/carousel.js picks this up from data-carousel and adds the paging controls. The viewport is a snapping scroll container that already holds every tile, so with JS off, by keyboard, or under a screen reader the whole group stays reachable and nothing is hidden. The three-rows-per-page shape is CSS — `--carousel-rows` on .people-carousel — and the script measures it off the DOM, so a breakpoint can change it without touching the JavaScript. Pass empty_state="open" to fall back to the open-positions panel when the group has no entries, which is what `current` does between cohorts. `current` is additionally shuffled per page load — see the script below the markup. `order` in _data/people.yml still decides the authored order, which is what the shuffle starts from and what stays on screen with JS off. {%- endcomment -%} {%- assign members = site.data.people | where: "group", include.group | sort: "order" -%} {%- assign label = include.label | default: "people" -%} {%- if members.size > 0 %}
